Kebijakan Privasi Lembar

Terakhir diperbarui: 14 November 2026

Lembar adalah aplikasi catatan buatan MangJaja. Kebijakan ini berlaku untuk aplikasi Lembar di Android dan untuk versi web Lembar di catetan.gampil.id. Halaman ini menjelaskan bagaimana Lembar memperlakukan data kamu.

Singkatnya: Lembar tidak mengumpulkan, mengirim, atau membagikan isi catatanmu. Semua catatan hanya tersimpan di perangkatmu sendiri, dan tidak ada akun. Aplikasi Android menampilkan banner iklan dari Google AdMob di halaman daftar catatan; penyedia iklan itu mengumpulkan sebagian data perangkat, seperti dijelaskan di bagian "Iklan" di bawah.

Data yang disimpan

  • Catatan: judul, isi teks, checklist, dan tulisan tangan yang kamu buat.
  • Pengaturan: misalnya pilihan "Hanya pensil", agar tidak perlu diatur ulang.

Di aplikasi Android, data ini disimpan di penyimpanan internal aplikasi dan tidak pernah dikirim ke server mana pun. Aplikasi Android memakai izin internet dan ID iklan hanya untuk menampilkan iklan (lihat bagian "Iklan"), dan tidak meminta izin lokasi, kamera, mikrofon, kontak, atau penyimpanan bersama.

Di versi web, data ini disimpan di penyimpanan browser (IndexedDB) pada perangkat yang kamu pakai, dan tidak dikirim ke server Lembar maupun pihak lain. Catatan di browser tidak tersinkron otomatis dengan HP; untuk memindahkan catatan, pakai file cadangan. Catatan di browser ikut terhapus kalau kamu menghapus data situs catetan.gampil.id.

Cadangan dan ekspor

Lembar bisa membuat berkas cadangan semua catatan, serta mengekspor catatan sebagai PDF, teks, atau gambar. Berkas ini hanya dibuat saat kamu memintanya, lalu disimpan ke lokasi yang kamu pilih sendiri (misalnya folder di perangkat atau Google Drive) atau dibagikan lewat aplikasi yang kamu pilih. Lembar tidak mengirim berkas tersebut ke mana pun secara otomatis. Setelah berkas disimpan atau dibagikan, pengelolaannya mengikuti layanan yang kamu pilih.

Cadangan bisa dilindungi password. Isinya lalu dienkripsi di perangkatmu sebelum disimpan. Password tidak disimpan oleh Lembar dan tidak dikirim ke mana pun, sehingga cadangan berpassword tidak bisa dibuka tanpa password tersebut, termasuk oleh pengembang.

Kunci aplikasi

Jika kamu mengaktifkan kunci aplikasi, Lembar meminta verifikasi memakai kunci layar perangkat (PIN, pola, sandi, sidik jari, atau wajah). Verifikasi sepenuhnya ditangani sistem Android. Lembar tidak pernah menerima, menyimpan, atau mengirim PIN maupun data biometrikmu; Lembar hanya menerima hasil berhasil atau gagal.

Data teknis saat membuka situs

Situs catetan.gampil.id di-host di server milik pengembang. Seperti situs web pada umumnya, server mencatat log akses standar saat halaman dibuka, yaitu alamat IP, waktu akses, halaman yang dibuka, dan jenis browser. Log ini hanya dipakai untuk keamanan dan mengatasi gangguan, tidak dipakai untuk iklan atau pelacakan, tidak dibagikan ke pihak lain, dan terhapus otomatis setelah sekitar 14 hari. Hal ini tidak berlaku untuk aplikasi Android.

Cadangan Android

Kalau fitur pencadangan Google diaktifkan di perangkatmu, Android dapat menyertakan data Lembar dalam cadangan akun Google-mu, sama seperti aplikasi lain. Pencadangan ini dikelola oleh Android dan Google, bukan oleh Lembar, dan bisa dimatikan di Pengaturan → Sistem → Cadangan.

Iklan

Aplikasi Android menampilkan satu banner iklan di bagian bawah halaman daftar catatan, disediakan oleh Google AdMob. Iklan tidak ditampilkan di editor catatan. Untuk memilih dan mengukur iklan serta mencegah penipuan, Google dapat mengumpulkan:

  • ID iklan perangkat (advertising ID) dan pengenal perangkat lain;
  • perkiraan lokasi berdasarkan alamat IP;
  • interaksi dengan iklan, seperti tayangan dan ketukan;
  • informasi teknis dan diagnostik, seperti jenis perangkat, versi Android, dan laporan error.

Isi catatan, judul, checklist, tulisan tangan, dan file cadanganmu tidak pernah dikirim ke Google AdMob maupun pihak lain. Penggunaan data oleh Google diatur dalam kebijakan Google tentang data dari aplikasi partner dan Kebijakan Privasi Google.

Kamu bisa mereset atau menghapus ID iklan, dan menolak iklan yang dipersonalisasi, di Pengaturan perangkat → Google → Iklan (nama menu bisa berbeda di tiap perangkat). Pengguna di Wilayah Ekonomi Eropa dan Inggris akan diminta persetujuan sebelum iklan dimuat, dan bisa mengubah pilihannya kapan saja lewat menu ⋮ → Pilihan privasi iklan.

Versi web dapat menampilkan satu banner iklan dari Google AdSense di bagian bawah halaman daftar catatan. Google dan partnernya dapat memakai cookie atau penyimpanan browser untuk menayangkan dan mengukur iklan, termasuk iklan yang dipersonalisasi berdasarkan kunjunganmu ke situs ini dan situs lain. Kamu bisa mengatur iklan yang dipersonalisasi di Setelan Iklan Google. Pengunjung dari Wilayah Ekonomi Eropa, Inggris, dan Swiss akan diminta persetujuan sebelum cookie iklan dipakai. Isi catatan di browser tidak pernah dikirim ke Google.

Selain iklan tersebut, Lembar tidak memakai alat analitik, cookie pelacak, atau SDK pihak ketiga lain yang mengumpulkan data.

Menghapus data

  • Android: hapus catatan satu per satu di aplikasi, atau buka Pengaturan → Aplikasi → Lembar → Penyimpanan → Hapus data, atau uninstall aplikasinya.
  • Web: hapus catatan di aplikasi, atau hapus data situs catetan.gampil.id lewat pengaturan browser.

Karena tidak ada akun dan tidak ada catatan di server, tidak ada data catatan lain yang perlu dihapus. Data iklan yang dikumpulkan Google dikelola lewat pengaturan iklan di akun dan perangkat Google-mu.

Anak-anak

Lembar tidak ditujukan untuk anak-anak. Pengembang tidak mengumpulkan data pribadi dari siapa pun; data yang dikumpulkan penyedia iklan dijelaskan di bagian "Iklan".

Perubahan kebijakan

Kalau kebijakan ini berubah, misalnya karena fitur sinkronisasi antarperangkat ditambahkan, versi terbaru akan dipasang di halaman ini dengan tanggal pembaruan yang baru, dan perubahan penting akan diberitahukan di dalam aplikasi.

Kontak

Pertanyaan tentang privasi Lembar bisa dikirim ke alamat email pengembang yang tercantum di halaman Lembar di Google Play.
