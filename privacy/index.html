Kebijakan Privasi Lembar

Terakhir diperbarui: 18 Oktober 2026

Lembar adalah aplikasi catatan buatan MangJaja. Kebijakan ini berlaku untuk aplikasi Lembar di Android dan untuk versi web Lembar di lembar.my.id (versi web sedang disiapkan). Halaman ini menjelaskan bagaimana Lembar memperlakukan data kamu.

Singkatnya: Lembar tidak mengumpulkan, mengirim, atau membagikan isi catatanmu. Semua catatan hanya tersimpan di perangkatmu sendiri. Tidak ada akun, iklan, atau pelacakan.

Data yang disimpan

  • Catatan: judul, isi teks, checklist, dan tulisan tangan yang kamu buat.
  • Pengaturan: misalnya pilihan "Hanya pensil", agar tidak perlu diatur ulang.

Di aplikasi Android, data ini disimpan di penyimpanan internal aplikasi. Aplikasi Android tidak meminta izin internet, lokasi, kamera, mikrofon, kontak, atau penyimpanan bersama, sehingga tidak bisa mengirim data ke mana pun.

Di versi web, data ini disimpan di penyimpanan browser pada perangkat yang kamu pakai. Isi catatan tidak dikirim ke server Lembar maupun pihak lain.

Data teknis saat membuka situs

Situs lembar.my.id di-host di server milik pengembang. Seperti situs web pada umumnya, server mencatat log akses standar saat halaman dibuka, yaitu alamat IP, waktu akses, halaman yang dibuka, dan jenis browser. Log ini hanya dipakai untuk keamanan dan mengatasi gangguan, tidak dipakai untuk iklan atau pelacakan, tidak dibagikan ke pihak lain, dan terhapus otomatis setelah sekitar 14 hari. Hal ini tidak berlaku untuk aplikasi Android.

Cadangan Android

Kalau fitur pencadangan Google diaktifkan di perangkatmu, Android dapat menyertakan data Lembar dalam cadangan akun Google-mu, sama seperti aplikasi lain. Pencadangan ini dikelola oleh Android dan Google, bukan oleh Lembar, dan bisa dimatikan di Pengaturan → Sistem → Cadangan.

Iklan, analitik, dan pelacakan

Lembar tidak menampilkan iklan dan tidak memakai cookie pelacak, alat analitik, atau SDK pihak ketiga yang mengumpulkan data.

Menghapus data

  • Android: hapus catatan satu per satu di aplikasi, atau buka Pengaturan → Aplikasi → Lembar → Penyimpanan → Hapus data, atau uninstall aplikasinya.
  • Web: hapus catatan di aplikasi, atau hapus data situs lembar.my.id lewat pengaturan browser.

Karena tidak ada akun dan tidak ada catatan di server, tidak ada data lain yang perlu dihapus.

Anak-anak

Lembar tidak ditujukan khusus untuk anak-anak dan tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan kebijakan

Kalau kebijakan ini berubah, misalnya karena fitur sinkronisasi antarperangkat ditambahkan, versi terbaru akan dipasang di halaman ini dengan tanggal pembaruan yang baru, dan perubahan penting akan diberitahukan di dalam aplikasi.

Kontak

Pertanyaan tentang privasi Lembar bisa dikirim ke alamat email pengembang yang tercantum di halaman Lembar di Google Play.
